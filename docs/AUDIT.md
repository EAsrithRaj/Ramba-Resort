# RAMBA — Stage A audit / 2 November 2026

## Inspected foundation

The project is a dependency-free static site: semantic HTML, CSS, browser JavaScript and Node.js ES modules for generation, preview and tests. No React migration or animation package is necessary.

Source: src/pages.mjs holds five pages; src/layout.mjs holds the shared shell. Root HTML and dist/ are generated by tools/build.mjs. tools/serve.mjs supplies a loopback preview, restricted public routes, CSP and a proper 404. Local DM Sans and Playfair Display fonts include SIL licences. tests/ holds build, link, server and enquiry tests.

The actual running pages were opened on 2 November: Home (9 sections), Our Story (4), The Experience (5), The Retreat (4), Enquire (3). Each rendered its expected heading without horizontal overflow at the initial desktop viewport. Baseline automated suite: 13 passed.

## Preserve

Five real document routes; accessible menu/escape/focus handling; skip link; native details accordions; keyboard-controlled moment selector; system and manual reduced motion; local enquiry validation, plain-text preview, encoded mail link and download. No backend, tracking, stored enquiry data, booking or availability claims. Keep stay@ramba.example unchanged and visibly non-operational.

## Weaknesses and gaps

Repeated split grids and decorative blocks create a flat rhythm. Repeated temporary media does not communicate a resort. Several colours sit outside the official palette. The old 9-section homepage is superseded by the new 7-section plus footer brief. The generated arch mark is not a supplied official logo. Browser enquiry/download verification in the prior report was incomplete. The build previously copied assets without clearing retired files from dist/.

Missing: approved transparent/vector logo, real property photography/footage, verified contact details, location/specifications/commercial details, opening date and approved legal/social URLs. None will be invented.

## Reference observations

The live https://www.thepearlclub.in/ was reviewed in the browser: immersive opening media; a persistent navigation layer; a quiet typographic pause after the hero; large experience imagery and clear artist-impression disclosures. These pacing principles inform an original RAMBA composition. No reference assets, code, wording, logo or distinctive layouts are reused.

## Implementation decision

Retain the existing build and four interior page compositions. Add a dedicated homepage template/style layer and a reusable conceptual-image helper. Generate ten cohesive original images, with WebP variants and portrait crops. Use native CSS masking, controlled sticky imagery, subtle scroll movement and the existing selector. Consolidate the brand palette and shared shell. Test the running result on desktop, tablet and mobile before the Stage E approval gate. No deployment.
